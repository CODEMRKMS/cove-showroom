  Walkthrough

  1. lib/ holds the pure logic: money (paise to ₹), filters (URL to API query),
     accent (paint to an accessible colour), carSpec (vehicle to drawing
     instructions) and stock.
  2. api/client.ts keeps the access token in a closure, so it never reaches web
     storage. On a 401 it does one shared refresh through the cookie and retries
     once. If that fails, it signs the user out.
  3. AuthContext restores the session on page load via refresh, then /auth/me.
     Route guards redirect and remember where the user was going.
  4. ShowroomPage keeps every filter in the URL. VehicleCard draws the car as an
     SVG and sets --accent from the chosen paint.
  5. Buying goes through a confirm dialog. The stock drops immediately in the UI
     and is restored if the server answers 409.
  6. The admin page derives its tiles from all cars. Edit leaves quantity out so
     every stock change goes through Restock and the event ledger.
  7. Modal traps focus, closes on Escape, restores focus, and hides the page
     behind it. Because of that, dialogs close before toasts are raised, so
     screen readers announce them.
  8. MSW plus a small stateful fake of the API lets the tests cover loading,
     empty, error and 409 flows.

  Interview questions

  1. Why keep the access token in memory and not localStorage? Script on the
     page can read localStorage, so an XSS bug would leak the token. A closure
     variable is lost on reload, and the httpOnly refresh cookie (which script
     can't read) restores the session.
  2. What does single-flight refresh solve? Refresh tokens are one-use and
     rotate. Three requests failing at once would otherwise send three
     refreshes, and the second would look like token reuse. They share one
     promise instead.
  3. Why are the filters in the URL? Links can be shared, the back button works,
     and the URL is the one source of truth. A debounced field remembers what
     it last pushed, so it can tell its own commits from outside changes such as
     Clear filters.
